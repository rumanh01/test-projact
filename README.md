# Calculator

A small calculator that runs in the browser. Everything lives in one file, `calculator.html`, so there is nothing to install.

## How to open

Double-click `calculator.html`, or open that file in any modern browser.

## What it can do

- Add, subtract, multiply, and divide
- Decimals and percent
- Clear (`C`) and delete the last digit (`←`)
- Show `Error` when a number is divided by zero

## Keyboard

| Key | Action |
| --- | --- |
| `0`–`9` | Enter a digit |
| `+` `-` `*` `/` | Choose an operation |
| `.` or `,` | Decimal point |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete the last digit |
| `Escape` | Clear |
| `%` | Percent |
